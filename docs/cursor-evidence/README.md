# Cursor Evidence

Cursor workflow evidence is part of the submission package. This directory documents the expected evidence files; screenshots or screencaps should be captured from the real development process and added separately.

Expected evidence:

- `01-planning`
- `02-review-feedback`
- `03-revised-plan`
- `04-implementation-milestones`
- `05-validation-run`
- `06-sample-report-generation`

Do not reconstruct final-state screenshots as process evidence. The evidence should show planning, iteration, implementation milestones, validation, and sample report generation.
